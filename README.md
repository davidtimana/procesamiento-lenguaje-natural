# Procesamiento de Lenguaje Natural

Este repositorio contiene ejercicios, proyectos y materiales de estudio relacionados con el procesamiento de lenguaje natural (NLP) para la especialización en IA.

## Contenido

- **Ejercicios prácticos de NLP** organizados por semanas
- **Proyectos de análisis de texto** con implementaciones completas
- **Material bibliográfico** y recursos de estudio
- **Notebooks de Jupyter** con análisis detallados
- **Implementaciones de algoritmos** de procesamiento de lenguaje natural

## Tecnologías

- **Python** - Lenguaje principal
- **NLTK** - Procesamiento de texto
- **spaCy** - Análisis lingüístico avanzado
- **Transformers** - Modelos de lenguaje
- **Scikit-learn** - Machine learning
- **Jupyter Notebooks** - Análisis interactivo

## Semanas de Estudio

### Semana 1-2: Fundamentos del NLP

### Semana 3: Análisis Avanzado
- Implementaciones prácticas con Python

### Semana 4: Redes Neuronales Recurrentes
- Investigación sobre RNN y LSTM

## Instalación

```bash
# Clonar el repositorio
git clone https://github.com/davidtimana/procesamiento-lenguaje-natural.git
cd procesamiento-lenguaje-natural

# Crear entorno virtual
python -m venv env
source env/bin/activate  # En Windows: env\Scripts\activate

# Instalar dependencias
pip install -r requirements.txt
```
